A classic Sudoku game designed for both desktop and touch screens. It includes
five difficulty levels, a bank of 120 checked puzzles, and on-device generation
for further games. Optional candidate assistance, notes, layered hints, and a
technique guide support beginners without changing the core rules.

Relaxed mode flags only repeated digits in a row, column, or box; strict mode
immediately counts incorrect entries. Completed games can be saved to a local
leaderboard. After the first online visit, the game can be installed to the
home screen and played offline.
