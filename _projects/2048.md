An independently built 2048 game for desktop and mobile browsers. Use arrow
keys or WASD on a computer, or swipe on a touch screen. The classic mode follows
the original 4×4 merging rules. An optional assisted mode adds limited undo,
swap, and delete actions, with more uses earned by creating larger tiles.

A short guided tutorial explains movement and merging. The game saves each
mode separately on the device and can be played offline after the first online
visit.
